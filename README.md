# 📝 Lista de Tarefas (To-Do List) em Python

Um programa de terminal simples para gerenciar tarefas do dia a dia, criado como parte dos meus estudos de fundamentos de Python.

## 🎯 Funcionalidades

- **Adicionar tarefa**: inclui uma nova tarefa na lista
- **Ver tarefas**: exibe todas as tarefas numeradas
- **Remover tarefa**: remove uma tarefa específica pelo número
- **Sair**: encerra o programa

## 🚀 Como executar

```bash
python todo.py
```

## 🧠 Conceitos praticados

- Variáveis e tipos de dados
- Listas (`append`, `pop`, `len`, acesso por índice)
- Laços de repetição (`while`, incluindo laços aninhados)
- Estruturas condicionais (`if` / `elif` / `else`)
- Entrada de dados do usuário (`input`) e conversão de tipos (`int`)
- F-strings para formatação de texto
- Construção de um menu interativo que mantém estado entre as escolhas
